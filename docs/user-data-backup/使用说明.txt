SubAI Translator —— 绿色免安装版
================================================

【如何启动】
双击「SubAI-Translator.exe」即可启动。

【文件说明】
- SubAI-Translator.exe    主程序（启动入口，双击这个）
- subai-backend.exe       后端服务（主程序会自动拉起，请勿手动运行）
- bin\ffmpeg.exe          音视频处理组件
- models\                 语音识别模型（faster-whisper-small）
- 源码\                   开发源码归档（运行程序不需要，可删除）

【使用提示】
1. 首次启动会自动加载后端与模型，请耐心等待几秒。
2. 关闭主程序后，后端服务会自动一并退出，无残留进程。
3. 分发时需整个文件夹一起拷贝（bin、models 必须与主程序同级），不能只拷贝单个 exe。
4. 「源码」目录为开发源码备份，仅作留档；日常使用或分发时可整目录删除以节省空间。

【重要：不要把 .env 一起分发】
如果本目录里有 .env 文件，里面可能写着云端翻译的 API Key。
分发前请把 .env 删掉，否则拿到拷贝的人可以直接用你的额度。
没有 .env 程序照样能跑，用户自己在「设置」里填 Key 即可。

【成品在哪】
生成的字幕在 output\ 目录；成品视频（软字幕 MKV / 硬字幕 MP4）与源视频放在同一目录，
文件名形如「原名_英语.mkv」，不会覆盖你的原始视频。
